# 📚 BCI Management System

A Flutter demo app for managing students, courses, and enrolments.

This project is built as an MVP with a modern Material 3 UI, in-memory storage, and a clean workflow for adding, editing, and viewing students and courses.

## ✨ Features

- 👥 Student management: add, edit, delete, search, and view student records
- 📖 Course management: add, edit, delete, search, and view course records
- 📝 Enrolment support: enrol students in courses, view enrolled students, and unenrol them
- 🏠 Welcome landing page before entering the main app
- 📱 Responsive UI with bottom navigation and search
- 💾 In-memory data store for demo purposes
